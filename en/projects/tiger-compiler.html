Context

Tiger is a small, statically typed imperative language from Andrew Appel's book Modern Compiler Implementation. It has structured types (records, arrays), nested functions, lexical scoping and explicit let … in … end blocks.

The goal: take a .tig source file and produce executable code, going through every stage of a real compiler — from lexical analysis all the way to register allocation.

Technical highlights

Lexing & parsing

Flex scanner and Bison grammar, with conflict resolution, operator precedence and located error messages (line / column).

AST & visitors

C++ abstract syntax tree traversed with the Visitor pattern: pretty-printer, binder, type checker and translator share the same hierarchy.

Name binding

Identifier resolution with nested-scope symbol tables, and detection of variables that escape into inner functions.

Type checking

Typing of expressions, recursive records and arrays; clear semantic errors instead of crashes.

Intermediate representation

Translation to an IR tree, then linearization and canonicalization into basic blocks before code generation.

Back end

Instruction selection by tree-pattern tiling, liveness analysis and register allocation by graph coloring.

let
  type intlist = { head: int, tail: intlist }
  function sum(l: intlist): int =
    if l = nil then 0
    else l.head + sum(l.tail)
  var l := intlist { head = 1,
           tail = intlist { head = 2, tail = nil } }
in
  print_int(sum(l))
end

Key takeaways

  • Understanding what really happens between source code and binary.
  • Designing a large, modular and testable C++ codebase (test suites for every stage).
  • Working as a team on a long project with code reviews and continuous integration.
