Hardware-proiektua

Testuingurua

Printzipioa sinplea da: robotaren alde banatan jarritako bi argi-sentsorek argi-intentsitatea neurtzen dute. Alde batek besteak baino argi gehiago jasotzen badu, motorrak biratu egiten du oreka berreskuratzeko — eta robota iturriari begira geratzen da.

Sinpletasun horren atzean: eskuratze analogikoa, zarataren iragazketa, oszilazioak saihesteko zona hila eta bi noranzkoetan dabilen motorraren kontrola.

Kontrol-begizta: argiaren neurketatik motorraren biraketara.

Puntu teknikoak

Eskuratzea

Fotoerresistentzia bakoitzak tentsio-zatitzaile bat osatzen du; tentsioa mikrokontrolagailuaren bihurgailu analogiko-digitalak irakurtzen du.

Kalibrazioa

Bi sentsoreek ez dute inoiz erantzun berdin-berdina: abiaraztean neurtutako desplazamendu batek aldea konpentsatzen du.

Iragazketa

Batez besteko mugikorra hainbat laginen gainean, zarata leuntzeko (fluoreszenteak, 50 Hz-ko keinua).

Zona hila

Atalase batetik behera, motorra geldi geratzen da: lerrokatuta dagoenean robota ez da dardaraka ibiltzen.

Kontrol proportzionala

Abiadura (PWM) errorearen araberakoa da: biraketa azkarra argia urrun dagoenean, motelagoa hurbiltzean.

Potentzia

H zubi batek mikrokontrolagailua motorraren korrontetik isolatzen du eta biraketa-noranzkoa aldatzea ahalbidetzen du.

Kode-zatia

C
#define DEADBAND 20

void loop(void) {
    int left  = read_avg(ADC_LEFT,  8);
    int right = read_avg(ADC_RIGHT, 8) + calib_offset;
    int err   = left - right;

    if (abs(err) < DEADBAND) {
        motor_stop();
    } else {
        int speed = clamp(abs(err) * KP, PWM_MIN, PWM_MAX);
        motor_set(err > 0 ? DIR_LEFT : DIR_RIGHT, speed);
    }
}

Zer ikasi dudan

  • Ideia sinple bat benetan funtzionatzen duen sistema fisiko bihurtzea (zarata, tolerantziak, mekanika).
  • Kontrolaren oinarriak: errorea, irabazia, zona hila, egonkortasuna.
  • Kontrol-logika eta potentzia-etapa garbiki bereiztea.
