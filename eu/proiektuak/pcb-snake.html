Testuingurua

Helburua: Snake jokoa exekutatzen duen kontsola txiki bat hutsetik diseinatzea — eskema elektronikoa, PCBaren bideratzea, soldadura, eta ondoren jokoaren firmwarea.

Erronka interesgarria: LED asko pin gutxirekin gidatzea. Hor sartzen da charlieplexing-a, GPIOen inpedantzia altuko egoera baliatzen duena n × (n − 1) LED n pin bakarrik erabiliz helbideratzeko.

Eskematik kontsola funtzionalera.

Puntu teknikoak

Charlieplexing

LED bat pizteko, pin bat 1era jartzen da, beste bat 0ra, eta gainerako guztiak sarrera gisa (inpedantzia altua). 9 pinekin: 9 × 8 = 72 LED helbideragarri, 8 × 8 sare baterako nahikoa.

Ekorketa

LED bakarra (edo lerro bakarra) pizten da aldi berean, baina ekorketa nahikoa azkarra da ikusmenaren iraunkortasunak irudi egonkorra erakusteko.

Bideratzea

Charlieplexing-aren kableatua trinkoa eta ez oso intuitiboa da: LEDen kokapenak eta pisten bideratzeak arreta berezia eskatu dute.

Sarrerak

Norabide-botoiak, software bidezko errebote-iragazkiarekin, freskatze-zikloen artean irakurriak.

Jokoaren logika

Sugea buffer zirkular batean gordeta, sagarraren sorrera, talken detekzioa eta abiaduraren igoera mailakatua.

Elikadura

Korronte-mugatzeko erresistentzien eta elikaduraren dimentsionamendua, distira homogeneoa lortzeko.

Kode-zatia

C
// Turn on the LED between pin `hi` (anode) and `lo` (cathode)
static void led_on(uint8_t hi, uint8_t lo)
{
    PIN_DDR  = 0;                    // all pins high-impedance
    PIN_PORT = 0;
    PIN_DDR  = (1 << hi) | (1 << lo);// only hi and lo become outputs
    PIN_PORT = (1 << hi);            // hi = 1, lo = 0 -> current through LED
}

ISR(TIMER_vect)                       // display refresh
{
    static uint8_t i = 0;
    if (framebuffer[i]) led_on(led_map[i].hi, led_map[i].lo);
    else                PIN_DDR = 0;
    i = (i + 1) % NB_LEDS;
}
