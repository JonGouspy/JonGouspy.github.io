Testuingurua

MPU6050 batek 3 ardatzeko azelerazioak eta abiadura angeluarrak ematen ditu. Teorian, azelerazioa bi aldiz integratzea nahikoa da posizioa lortzeko. Praktikan, alborapenik txikiena ere lehertu egiten da: segundo gutxiren buruan posizioa hainbat metro desbideratzen da.

Proiektu honek bi teknika uztartzen ditu estimazioa erabilgarria izan dadin: Madgwick iragazkia, sentsorearen orientazioa ezagutzeko, eta ZUPT zuzenketa (Zero Velocity Update), sentsorea geldi dagoen bakoitzean abiadura zerora itzultzeko.

Puntu teknikoak

I²C driverra

MPU6050arekiko komunikazioa ESP-IDFren I²C APIaren bidez: tarteen konfigurazioa (±g, °/s) eta erregistroen irakurketa jarraitua.

FreeRTOS atazak

Maiztasun finkoko eskuratze-ataza bat eta prozesamendu-ataza bat; ilara baten bidez trukatzen dituzte datuak, laginketa erregularra bermatzeko.

Madgwick iragazkia

Giroskopioaren eta azelerometroaren fusioa, orientazio-kuaternioi baten gaineko gradiente-jaitsieraren bidez, β parametroaz doitua.

Munduko erreferentzia

Azelerazioa Lurraren erreferentzia-sistemara biratzen da kuaternioiari esker, eta grabitatea kentzen zaio azelerazio lineala soilik gordetzeko.

Geldiune-detekzioa

Leiho irristakor batean: azelerazioaren norma g-tik hurbil eta biraketa ia nulua → sentsorea geldi dagoela jotzen da.

ZUPT zuzenketa

Geldiune bakoitzean abiadura zerora behartzen da: metatutako errorea mozten da eta posizioaren desbideratzea mugatuta geratzen da.

Kode-zatia

C
static bool is_stationary(const imu_sample_t *s)
{
    float a_norm = vec3_norm(s->acc);          // in g
    float w_norm = vec3_norm(s->gyro);         // in rad/s
    return fabsf(a_norm - 1.0f) < ACC_TH && w_norm < GYRO_TH;
}

void process(imu_sample_t *s, float dt)
{
    madgwick_update(&q, s->gyro, s->acc, BETA, dt);
    vec3 a_world = quat_rotate(q, s->acc);
    a_world.z -= 1.0f;                         // remove gravity

    if (window_all(is_stationary)) vel = VEC3_ZERO;   // ZUPT
    else vel = vec3_add(vel, vec3_scale(a_world, G * dt));

    pos = vec3_add(pos, vec3_scale(vel, dt));
}

Zer ikasi dudan

  • ESP-IDFrekin garatzea eta denbora errealeko aplikazio bat FreeRTOSekin egituratzea.
  • Sentsore-fusioa eta kostu baxuko IMU baten muga fisikoak ulertzea.
  • Desbideratze bat aurretiazko ezagutzaren bidez zuzentzea (hemen: geldiuneak).
