Testuingurua

Tiger lengoaia inperatibo txiki eta tipatua da, Andrew Appel-en Modern Compiler Implementation liburutik datorrena. Datu-mota egituratuak (erregistroak, arrayak), funtzio habiaratuak, esparru lexikoak eta let … in … end blokeak ditu.

Helburua: .tig iturburu-fitxategi batetik abiatuta kode exekutagarria sortzea, benetako konpilatzaile baten urrats guztiak zeharkatuz — analisi lexikotik erregistroen esleipeneraino.

Puntu teknikoak

Analisi lexikoa eta sintaktikoa

Flex eskanerra eta Bison gramatika, gatazken kudeaketarekin, eragileen lehentasunekin eta kokatutako errore-mezuekin (lerroa / zutabea).

AST eta bisitariak

C++-ko zuhaitz sintaktiko abstraktua, Visitor diseinu-ereduaren bidez korritua: pretty-printerrak, binderrak, tipo-egiaztatzaileak eta itzultzaileak hierarkia bera partekatzen dute.

Izenen lotura

Identifikatzaileen ebazpena esparru habiaratuetako ikur-taulekin, eta barneko funtzioetara «ihes egiten» duten aldagaien detekzioa.

Tipo-egiaztapena

Adierazpenen, erregistro errekurtsiboen eta arrayen tipatzea; errore semantiko argiak, programa kraskatu beharrean.

Tarteko adierazpena

IR zuhaitzera itzultzea, eta ondoren oinarrizko blokeen linealizazioa eta kanonizazioa, kodea sortu aurretik.

Back-enda

Agindu-hautaketa zuhaitz-ereduen bidez, bizitasun-analisia eta erregistro-esleipena grafoen koloreztatzearen bidez.

Kode-zatia

Tiger
let
  type intlist = { head: int, tail: intlist }
  function sum(l: intlist): int =
    if l = nil then 0
    else l.head + sum(l.tail)
  var l := intlist { head = 1,
           tail = intlist { head = 2, tail = nil } }
in
  print_int(sum(l))
end

Zer ikasi dudan

  • Iturburu-kodearen eta bitarraren artean benetan gertatzen dena ulertzea.
  • C++ kode-base handi, modular eta probagarri bat diseinatzea (proba-multzoak urrats bakoitzeko).
  • Taldean lan egitea proiektu luze batean, kode-berrikuspenekin eta integrazio jarraituarekin.
