Testuingurua

Ziklo bakarreko prozesadore batek agindu bakoitza osorik — bilaketa, deskodetzea, exekuzioa, memoria-sarbidea, idazketa — erloju-ziklo bakar batean exekutatzen du. Arrazoitzeko arkitekturarik sinpleena da, eta ondoren pipeline-a ulertzeko oinarria.

Proiektuan datu-bideko bloke bakoitza VHDLz deskribatu, kontrol-unitate batekin elkartu eta dena simulazioan balioztatzen da benetako programekin.

Ziklo bakarreko prozesadorearen datu-bidea.

Puntu teknikoak

ALU

Eragiketa aritmetiko eta logikoak, eta baldintzapeko jauzietarako erabiltzen diren adierazleak (N, Z, C, V).

Erregistro-bankua

Bi irakurketa-ataka asinkrono eta idazketa-ataka bat, erloju-ertzean sinkronoa.

Kontrol-unitatea

Opcode-a kontrol-seinaletan deskodetzea: multiplexoreen hautaketa, erregistro / memoria idazketa, ALU eragiketa.

Memoriak

Programarekin hasieratutako agindu-memoria eta datu-memoria bereizia (Harvard arkitektura).

PCaren kudeaketa

Inkrementua, jauzi erlatiboak eta saltoak, adierazleen arabera multiplexore batek hautatuak.

Egiaztapena

Testbench bat entitate bakoitzeko, eta ondoren testbench global bat, programa bat exekutatu eta amaieran erregistroak egiaztatzen dituena.

Kode-zatia

VHDL
entity alu is
  port (
    op     : in  std_logic_vector(1 downto 0);
    a, b   : in  std_logic_vector(31 downto 0);
    s      : out std_logic_vector(31 downto 0);
    n_flag : out std_logic
  );
end entity;

architecture rtl of alu is
  signal res : signed(31 downto 0);
begin
  with op select res <=
    signed(a) + signed(b) when "00",
    signed(b)             when "01",
    signed(a) - signed(b) when "10",
    signed(a)             when others;

  s      <= std_logic_vector(res);
  n_flag <= res(31);
end architecture;

Zer ikasi dudan

  • Hardwarean pentsatzea: konkurrentzia, seinaleak, denbora, agindu-sekuentzia baten ordez.
  • Agindu bat seinale elektriko bihurtzen den modua zehazki ulertzea.
  • Simulazio bidezko egiaztapenaren garrantzia edozein sintesi egin aurretik.
