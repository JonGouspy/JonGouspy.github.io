Testuingurua

Kamera finko batek grabatutako bideo batean, dekoratuaren parte ez den guztia objektu interesgarria da. Ideia: hondoaren eredu bat ikastea, eta ondoren irudi bakoitzean hartatik aldentzen diren pixelak isolatzea.

Kalkulua pixel bakoitzerako independentea denez, ezin hobeto egokitzen zaio GPUari. Proiektuan CPU erreferentziazko bertsio bat idatzi, CUDA kernel-etara eraman eta irabazia neurtzen da.

Puntu teknikoak

Hondoaren eredua

Hondoa bideoan zehar estimatu eta eguneratzen da (batez besteko mugikorra), argiztapenaren aldaketa geldoetara egokitzeko.

Mugimendu-maskara

Uneko irudiaren eta hondoaren arteko distantzia, eta ondoren histeresidun atalasea: atalase altua abiatzeko, baxua hedatzeko.

Morfologia

Higadura eta ondoren dilatazioa, zarata isolatua kentzeko eta objektuetako zuloak betetzeko.

Hari bat pixel bakoitzeko

Kernel bakoitzak hari bat lotzen dio pixel bakoitzari; 2D sareak eta memoria-sarbide bateratuak.

Memoria partekatua

Auzo-eragiketek (morfologia) lauza bat eta haren ertza memoria partekatuan kargatzen dituzte, memoria globala berriro ez irakurtzeko.

Benchmarka

CPU eta GPU arteko konparazioa eta profilatzea (Nsight), banda-zabaleraren mende dauden kernelak identifikatzeko.

Kode-zatia

CUDA
__global__ void diff_threshold(const uchar3* frame, const float3* bg,
                               uint8_t* mask, int w, int h, float th)
{
    int x = blockIdx.x * blockDim.x + threadIdx.x;
    int y = blockIdx.y * blockDim.y + threadIdx.y;
    if (x >= w || y >= h) return;

    int i = y * w + x;
    float3 d = make_float3(frame[i].x - bg[i].x,
                           frame[i].y - bg[i].y,
                           frame[i].z - bg[i].z);
    float dist = sqrtf(d.x*d.x + d.y*d.y + d.z*d.z);
    mask[i] = dist > th ? 255 : 0;
}
